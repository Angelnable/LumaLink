# LumaLink 阶段 10：交互与镜头适配

日期：2026-10-20
版本：2.4.0-debug

## 1. 遥控

- 去掉“开始监看”和“开始/停止录像”的二次确认弹窗。
- 按钮点击直接执行；拍照原本就是直接执行。
- 首次命令仍保留连接级错误最多重试一次。
- 录像/快门按钮统一 78dp、32dp 图标。

## 2. 镜头光圈

- 连接后读取：
  ```text
  /cam.cgi?mode=getinfo&type=lens
  ```
- 解析字段 2（当前最大光圈）与字段 1（当前最小光圈），值形如 `896/256`。
- 遥控页光圈下拉只显示该镜头范围内的数值。
- 读取失败时回退完整 f/1.7–f/16 列表。

## 3. 传输历史

- 已完成/失败/取消支持“删除记录”。
- 已完成记录支持“删除记录 + 本地文件”。
- 新增批量选择：全选/取消全选，批量删除记录或记录+文件。
- 切换 Tab 会退出批量选择。

## 4. 相机相册

- 相机文件按拍摄时间倒序；无日期时按文件名倒序。
- 顶部图标/列表切换。
- 图标模式 4 列，点按直接打开预览；已加载过的缩略图会缓存显示。
- 列表模式左侧预览图/类型图标，右侧文件名、类型、大小、拍摄时间。
- 保留“眼睛”预览按钮；预览读取 `DT...JPG`。

## 5. 验证

- `:app:assembleDebug` 成功
- `:app:assembleDebugAndroidTest` 成功
- `:app:lintDebug` 通过
- 非 LUT JVM 测试 45 个通过
